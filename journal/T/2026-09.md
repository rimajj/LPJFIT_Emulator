## 2026-09-09 — the roster was valid and not viable

Picked up the handoff's item 1, "add `agb` to `MATCH_TRAITS`", and did not do it, because the
measurement that was supposed to confirm it refuted it instead. Before changing the matching
objective I read the state summary of the restart file that had actually been written, rather than
inferring it from the model run: its above-ground biomass was 4,030 gC/m2 against a true 3,777 —
6.7 % HIGH. The synthesis had never lost any carbon. The loss was in the simulated year.

Comparing the roster in with the roster out, for both arms, made it obvious: the control keeps 96 %
of its stems, the emulated arm keeps 51 %. And the model says why per individual. Every one of the
2,372 tropical broadleaved evergreens had `mort_temp` exactly 1.000 — certain death — because that
type is charged a stress day for every day below 12.5 C and dies at 73 of them. The donor pool was
built to span biomes and the donor choice never looked at the tree type, so a third of the stems
planted in temperate Germany were Amazonian.

Three gates had passed this file: byte-identical round-trip, config pre-flight, and a one-year run
that did not abort under `-DSAFE`. None of them could see it. The thing I want to remember is the
shape rather than the specifics — a validity check on the parts is not a viability check on the
whole, and "the model did not abort" is not "the model accepted the state". It repaired the state,
loudly, and reported success.

Fixing it moved the constraint rather than removing it, which is how you know the diagnosis was
right: with types constrained the donor pool became binding (983 tall beech needed, 50 available),
so the pool went from 6,745 stems to 25,424 by proximity band. Carbon after one year: 0.543 → 0.296
→ 0.091, and the state is now stationary. Deliberately did NOT pick the donor cells that were
richest in what this block lacked — that would be selecting the donor set against the answer.

Then tested the next obvious idea and killed it: matching five traits instead of two is worse (11
of 22 quantities degrade). One donor is one real stem; it cannot sit at the same quantile of five
distributions at once. Recorded in the module so nobody spends an afternoon on it.
