### Added

- **A stem field may now be IMPOSED — written into the transplanted stem's bytes — instead of inherited from whichever donor was chosen, and the licence for it is read off the model's source rather than assumed.** `IMPOSED_TRAITS` admits a field only if all three hold: the C never recomputes it, it drives no physics, and it is still load-bearing for the state. `D95max` passes: every write to `tree->D95max` is at tree birth (`tree/new_tree.c:124,179,209,233`), `allocation_tree.c` writes `tree->D95` which is a different field, rooting depth proper comes from `getrootdepth(height, k_root, model)` which never reads it — and offspring inherit it with mutation, so the roster's distribution seeds the next generation's. Leaf carbon looks similar and FAILS the second test, because `allometry_tree.c:39-41` derives height from it. This relaxes "no individual stem is ever edited" to a rule with one named exception; adding a second field means re-reading the C for that field, not reasoning by analogy.
- **`.claude/skills/cmodel-run/SKILL.md`** — the module set the C model needs, the free config pre-flight, and the one line that counts as success. `slurm-guard.sh`'s deny message has pointed at this skill all along and it did not exist; its absence cost three failed jobs in a row.

### Fixed

- **The synthesiser's rooting-depth cap is gone.** Donor selection provably could not deliver this quantity — with a PERFECT prediction the match still left `D95max_p50` at 0.127 — because one donor is one real stem and cannot sit at the right quantile of three distributions at once. Imposition collapses the emitted file's error against its own input from 0.072 to **0.007** at the median and from 0.119 to **0.003** in the low tail.

### Changed

- **And it is shipped SWITCHED OFF, because it makes fidelity worse today.** `IMPOSED_TRAITS = ()`. The level model's own rooting-depth error is larger than the donor accident it replaces: |pred−true| is 0.141 at the median and 0.179 in the low tail, against the 0.119/0.177 that inherited donor values happened to achieve. Reproducing a wrong prediction faithfully is worse than inheriting a lucky one, and the twenty-year score says so — conjunctive 5 % → 0 %, median 18/22 → 17/22, with every other scored quantity unchanged to three decimals. Verified inert: synthesising with the default reproduces `synth-v5` **byte-identically** (sha256 `1e856119…`), so the deliverable is unchanged. Turn it on when the `D95max` prediction beats roughly |pred−true| = 0.12 at the median, and turn it on regardless before quoting any warmed-climate product — a donor's rooting depth is a present-day value from a neighbouring cell, so the accident that currently helps cannot shift with climate, and the warming response is the acceptance criterion's binding clause.
- **Predicting `D95max` is now the whole remaining rooting-depth gap**, and the synthesiser is out of the way of it. Both scored objects had pointed at rooting depth; only one half was the synthesiser's to fix, and that half is done.

- **Two defects in `scripts/sbatch_cmodel.sh` are now written down, though neither is fixed here — line D owns that wrapper.** ⚠ It **pins no modules**: it submits with `--export=ALL` and no `module load`, so a C run inherits whatever the submitting shell had, and from a shell with none the model dies in under a second on `libnetcdf.so.19`, then `libudunits2.so.0` — one library per attempt. Three jobs were lost to it. ⚠ And `grep -c 'successfully terminated'` — the wrapper's own suggested harvest command — **returns 1 on a FAILED job**, because the wrapper's trailing NOTE contains the phrase; measured on a job that died with exit 127 in zero seconds. Anchor it as `grep '^lpjml successfully terminated'`. Both, plus the recipe for recovering a working module set from any green run's own log, are in the new `cmodel-run` skill.
- ⚠ **Line D cannot currently be sent a message at all.** `lines/D/STATE.md` sits at exactly its 120-line budget, so the 8-line block `tools/inbound.py` appends pushes it over and reddens the `budgets` gate for everyone. The message above was written, measured to break the gate, and reverted rather than shipped red. **D must rotate before any line can reach them** — which also means an inbound sent by a session that does not check will either be dropped or will redden main.
