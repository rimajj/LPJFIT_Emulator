### Added
- **The synthesiser can now build a restart file for a place under a climate that place was never simulated under, taking the climate memory, the allowed tree types, the species mix and the donor trees from that climate rather than copying them from the place's present-day file.** Every new behaviour ships switched off. With the switches off the synthesiser writes exactly the bytes it wrote before. A test on the real files re-creates the delivered 20-cell restart file record for record, and a second test checks fixed fingerprints computed with the code as it was before this change.
- **The restart's climate memory is now computed from the climate input, and on the pilot it reproduces the model's own values to the last bit.** The model recycles its 30-year climate for 1,000 years in a random order. That order comes from one random-number stream seeded by the run's seed setting, so it can be replayed exactly. The check: over all 6,000 pilot simulations (200 places × 30 climates, CO₂ fixed) the random-number state after the replay matches the one stored in each restart file, and every field the climate determines is identical to the bit: the 20-year coldest-month and warmest-month records, the monthly 20-year means, the degree-days and the last month of daily weather. The crop-only vernalisation fields agree to within one part in 10¹³. Two fields depend on the vegetation, not the climate, and so cannot be computed this way. Potential evaporation, estimated from the present-day file's own reflectivity, is off by a median 5.9 % across the 5,800 changed climates. Mean actual evaporation, copied from the present-day file, is off by a median 16.5 %. Neither is read by forests in this model setup: the first is used only for crops, the second only for nitrogen fixation, which is switched off.
- **The tree types allowed at a place now follow the model's own climate limits under the target climate.** The old rule was "types already present at that place today", and for a place with no trees today it allowed any type at all. The new rule allows a type only if it passes the model's own cold-limit survival test and could have established in at least one year of the replayed spin-up. Across all 6,000 pilot simulations, checked against each one's true forest: it keeps 99.78 % of the true trees and admits 4.0 % of the types that are absent. For comparison, "any of the 10 most similar climates elsewhere has it" keeps 99.93 % but admits 24 %. Every tree the new rule drops belongs to a type the model itself kills in its next yearly step (mostly this year's new boreal larch-like trees, at places whose summer-to-winter temperature range is below that type's minimum).
- **The species mix can now be given as an input.** The number of trees of each type is then exact. Each type's trees are drawn from that type's own height distribution, so types that are tall at a place stay tall. A type absent from the present-day file takes its sizes from donor trees of that type.
- **Donor trees can now be chosen by climate similarity, never from the same 15° region group as the place being built.** The code checks that none come from the place itself or from its held-out group.
- **The litter can now be rescaled along with the soil carbon.** Checked with the true values on 5,362 changed-climate pilot simulations: scaling the present-day litter by the true soil-carbon ratio gives a median error of 21.7 % (27.6 % of simulations within 10 %). Copying the litter unchanged gives 28.9 % (21.2 %). Scaling by forest carbon, above-ground biomass or leaf area is worse than copying.
- **A pilot test harness, `scripts/synth_pilot.py`.** For each of the 200 pilot places and each of its 29 other climates it builds the forest from the place's present-day file. It does this two ways: from the true answer, which measures the synthesiser's own loss, and from the climate-only map's out-of-fold predictions (whose folds were checked to match the donor folds). All 11,600 files load back byte-identically and contain no disallowed tree. It then runs the real model for one year on a sample of 40 places × 3 climates (the hottest, the coldest and +4 °C), under that climate's own weather. All 600 runs completed. The files are prepared, but not launched, for a 30-year continuation of all 5,800 targets per arm: an estimated 46 core-hours for all four arms, from the measured one-year run time and the pilot spin-ups' own cost per simulated year.

### Changed
- **What a perfect prediction still loses, measured.** These are diagnostics, not registered results: pilot only, 5,800 targets at year 0 and 120 after one year. With the true answer as input, tree counts, soil carbon and height and wood-density percentiles come out within 1 % (median). Above-ground biomass comes out 17 % off at the median: the donor match targets height and wood density, not mass. After one model year, 22.7 % of the synthesised trees have died, against 16.8 % for the model's own forest. For trees older than one year the rates are 11.2 % against 5.5 %. The trees carried over from donors with a bad-growth history are not the cause. Deriving the climate memory instead of copying it makes no difference in that first year (22.6 % against 22.7 %). Its job is the 20-year survival and establishment tests, which one year cannot show.
