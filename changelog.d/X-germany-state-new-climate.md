### Added

- **The Germany runs' tree counts and traits are now readable, and a first test on them: the emulator predicts the whole settled forest under a climate it never trained on clearly better than any shortcut, but not yet as well as a second run of the model.** Each run's year-3070 state file (the last full state before the humidity input goes wrong; ~200 GB each, twelve files) was first proven readable: 49 cells per file re-written byte for byte, and the carbon read out of each file equal to the model's own carbon output to within 6 parts in 100 million. Every cell was then decoded into tree count, stocks, and the spread of five traits (4.4 minutes on 64 cores). Holding out one climate at a time and asking for all 19 quantities at once, the map gets every one inside the tolerance band in 43.7 % of the 54,402 cell-climate pairs; a second run of the model manages 49.4 %, and the pre-registered rule needed 47.4 %, so the test fails by 3.7 percentage points. The best shortcut, copying the same cell's state from its most similar training climate, gets 12.9 %; the same learners given soil alone 6.4 %. The largest shortfalls are leaf longevity, the small-tree end of the maximum-diameter trait and tree count, and the worst held-out climate is MPI-ESM1-2-HR ssp245 (28.9 % vs 51.0 %). The ssp245 runs were made on a newer model build that changed how new trees inherit traits, which may explain that fold; this is not yet tested. Only one year per seed is available, so a second run agrees on everything in only about half the cells. New: the `restart` and `state` stages of `scripts/germany_corpus.py`, and `scripts/exp_germany_state.py`.
