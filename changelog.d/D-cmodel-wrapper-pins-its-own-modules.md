### Fixed

- **`scripts/sbatch_cmodel.sh` now loads its own module set, so a C run no longer depends on who submitted it.** The wrapper submitted with `--export=ALL` and no `module load`, so the job inherited whatever the submitting shell happened to have; the same command was a green run from one session and a one-second death from another. Measured here: with no modules loaded the binary is short exactly two libraries — `libnetcdf.so.19` and `libudunits2.so.0` — and the loader names one per attempt, so chasing them singly costs a job each. Three of line T's jobs were lost to it. The job now purges and loads a pinned `LPJ_MODULES` set (recovered from job 2080497's own log, overridable by env), and then **checks with `ldd` that the binary actually resolves before spending the allocation** — turning a cryptic loader death into a named diagnosis that names the missing library and how to recover a working set.
- ⚠ **The pre-flight was never module-free, though the skill said it was.** `scripts/sbatch_cmodel.sh --check` runs `lpjcheck`, which links the same libraries as `lpjml`, so from a shell with no modules it died with the identical `libnetcdf.so.19` message — **in the one command whose entire purpose is to tell you whether the config is good**, where a missing environment reads as a broken config. The module set is now loaded in the wrapper's own shell before `lpjcheck` runs, and the claim has been corrected in the `cmodel-run` skill. Verified: `--check` now passes from a shell with no modules loaded.
- **The wrapper no longer plants a decoy that makes a dead job look green.** `grep -c 'successfully terminated'` returned 1 on a job that died with exit 127 in zero seconds, because the wrapper echoed the phrase into every job log as advice — and that unanchored grep was the harvest command the wrapper itself recorded into the campaign ledger. Both halves are fixed: every recorded harvest command is now anchored as `grep '^lpjml successfully terminated'` (the model's own line starts a line; the advice text never did), **and** the trailing NOTE no longer contains the phrase at all, so even a careless unanchored grep cannot match it. The runner's internal per-member verdict is anchored too.

### Changed

- **The wrapper's header now documents six traps rather than four**, the two new ones being the module inheritance and the decoy grep, each with the measurement that produced it.
