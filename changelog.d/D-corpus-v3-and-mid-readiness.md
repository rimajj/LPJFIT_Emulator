### Added
- **A new version of the training table, built from the existing simulations without running the model again.** It holds the same 6,000 simulated forests (200 locations, each under 30 climates, CO₂ held fixed) as the previous version and adds the five soil-texture columns the latest experiment had to attach by hand every time it read the table: the soil type, how much water the soil can hold for plants, the fraction of the soil that water fills, and the sand and clay content. Checked column by column against the previous version: 174 of the 181 columns it shares with the old table are identical on every row. The other 7 are the tree-type shares, and they differ only on the 380 rows with no trees at all. The five soil columns match what the experiment computed, to the last digit, on all 6,000 rows. The previous table still exists and is untouched. It is named `pilot-v3-constco2`, and its records list a fingerprint of each of the 6,000 model restart files it was read from, so anyone can check that no new simulation went into it.
- **The planned larger training set (1,000 locations × 100 climates × 2 simulation seeds, CO₂ fixed) can now be planned correctly. It has been planned as a dry run only; nothing was built or run.** It contains all 200 locations and all 30 climates of the existing set, so every existing result can be checked against it. It covers every one of the 164 populated 15° regions. Projected cost, from the per-simulation cost measured on the existing set: about 6,000 core-hours per seed, 12,000 for both, and roughly 1.9 times that in billed time unless runs are packed together. Disk: about 434 GB of run output plus 22 GB of climate input. These are projections, not measurements.
- **The fixed CO₂ level can now be set to something other than the pre-industrial 276.59 ppm.** Behind the scenes, a CO₂ file at any other level has to start by model year 1000. Before its first year the model quietly uses its own 276.59, so a file starting at the usual year 1700 would have put a CO₂ jump 700 years into a run that is supposed to be steady.

### Changed
- **A training table no longer records 0 % of every tree type for a place with no trees.** With no trees, the share of each type is undefined, and the table now says so. The old tables keep their old values, because each one is fingerprinted in a registered experiment: re-running the old reading code reproduces both of them exactly (the 181-column table and the 78-column one), which was checked.
- **Planning a training set now records the CO₂ setting and the simulation seed in the plan's fingerprint.** Before, the plan for a second seed, or for a fixed-CO₂ rerun, had the same fingerprint as the original. The old fingerprint is still recorded, under a new name, so existing references to it stay valid. Re-planning, in place, a training set that was planned before this change is refused, because doing so would replace the fingerprint that registered experiments cite with one computed the new way.
- **A rebuilt table that fails its column-by-column comparison with the table it was rebuilt from no longer takes that table's name.** It is saved under a name marked as refused, and its fingerprint is left out of the run's record, so it cannot be cited by mistake or overwrite an accepted table.
- **The step that writes model configurations now takes the CO₂ setting from the plan and refuses a command that contradicts it.** Before, forgetting one command-line option would have produced rising-CO₂ runs under a plan that said fixed CO₂. The pre-launch check now opens every run's CO₂ input and confirms which CO₂ value the model will actually use in each simulated year. Planning a second simulation seed is likewise refused if its CO₂ setting or its set of climates differs from the first seed's, because the two would then not be repeats of the same simulation.
- **The spin-up drift check now also measures the trend over a stretch when CO₂ was constant.** Its old window, the last 200 years, falls entirely inside the historical CO₂ rise. That is how CO₂-driven growth was once reported as the spin-up failing to settle. Re-run on the stored simulation of all 67,420 locations (a diagnostic, not a registered result): the typical location's forest carbon changes by +0.4 % per century while CO₂ is constant, against +6.8 % over the last 200 years. For the global total the figures are −0.3 % and +6.5 %. Every number the check reported before comes out exactly as it did.

### Fixed
- **Asking for more than 472 locations silently returned 472.** A fixed cap of 3 locations per region limited every design, however large the request. The cap now grows with the size of the design, and a request the design cannot meet is refused, not trimmed. At the existing set's size the choice of locations is unchanged, which was checked by fingerprint.
- **Soil code 13 means "rock and ice" to the model, not "light clay".** The hand-copied soil table used by one experiment script had it wrong. No tree-bearing location has code 13, so no result was affected, but the new soil columns now follow the model's own files, and a test re-reads those files to confirm every value.
