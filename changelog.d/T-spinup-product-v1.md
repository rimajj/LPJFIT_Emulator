### Added

- **The first restart file of the whole globe at the end of the stored spin-up's constant-CO2 stretch (model year 1699).** The stored 1000-year spin-up only ever wrote a restart at its end, after 300 years of rising CO2. This file is every cell's forest, soil and climate memory as the emulator predicts them for 1699, at 276.59 ppm: the species mix from the climate-only map's held-out predictions, the tree types the model's own climate limits allow, and each cell's climate memory rebuilt year by year from its own 1901-1930 weather in the exact order the stored run drew those years. 56,986 cells were rebuilt, 10,434 cells with no tree were copied unchanged, 32.2 million stems were placed; the file reads back record for record and the model's own pre-flight accepts it. It took 11 core-hours to write. As a dev diagnostic (no claim), its vegetation carbon before the model runs is inside the acceptance band in 18.7 % of cells, where a second run of the model is inside it in 85.9 %; the stored run's own 1999 state scores 18.9 %.
- **Proof that the stored run's year sequence is reproduced exactly.** Replaying the stored spin-up to 1999 from the global weather files reproduces the climate memory in its 1999 restart bit for bit on 240 cells spread over the globe, and lands on the same random-number state the file records. The same replay stopped at 1699 is what the new restart carries.
- **A reader of the model's own total vegetation carbon from a restart** (trees and grass, as the model's output sums them). It matches the stored run's own output for 1999 on all 67,420 cells to the last stored digit.
- **A global continuation run from any restart** (`scripts/spinup_continuation.py`): the real model continues the stored spin-up's own protocol for 30 years at constant 276.59 ppm, split into 1,015 pieces that together cover every cell. Continuing the stored run's own 1999 state this way cost 155 core-hours and shows how far the model is from its constant-CO2 equilibrium when it starts from the CO2-ramped forest: inside the band in 29.2 % of cells over the first 10 years and 41.0 % over years 21-30, with a sudden mass die-off in year 5 (a third of global vegetation carbon moves to litter in one year) and steady regrowth after it.
- **A draft pre-registration** (`X-20260925-spinup-restart-continuation`, not sealed) that scores the new restart the same way, against that measured null.
